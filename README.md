# .github

Default community health files for every repository in this account. GitHub applies
these to any repository that does not define its own, so a fix here is a fix everywhere.

| file | why it exists |
|---|---|
| [`SECURITY.md`](SECURITY.md) | how to report a vulnerability privately, what is in scope, and what to expect — this account publishes security tools, so the tools themselves need a reporting route |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | the evidence rule: a change needs a test that fails before it and passes after it |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1, with a private enforcement contact |
| [`ISSUE_TEMPLATE/`](ISSUE_TEMPLATE) | bug and feature forms that ask for the version, the expectation, and the reproduction |
| [`PULL_REQUEST_TEMPLATE.md`](PULL_REQUEST_TEMPLATE.md) | asks what was verified and what was not |
